# Unity project

The complete Unity project is provided in `NPCMemoryVillage-UnityProject.zip` in this folder. Download the ZIP and extract it; then open the extracted `NPCMemoryVillage` directory in Unity Hub. The archive includes `Assets`, `Packages`, and `ProjectSettings`, with generated cache folders omitted.

Built with Unity 6000.3.27f2. The BackendConfig asset points to `http://127.0.0.1:8001/chat` by default. Start FastAPI and Ollama before testing live NPC replies. See the repository root README for backend setup.
